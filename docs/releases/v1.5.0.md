## 新功能

- **自定义弹窗菜单**：在「设置 → 外观 → 菜单功能」中，左侧预览常用功能，右侧添加按钮；点击预览按钮即可移除，拖动时自动吸附并调整顺序，也可将两个短按钮组合成一行。GitHub 与官网链接固定在底部。
- **自定义局部快捷键**：段落点击、划词原文提交、关闭浮层、悬浮球翻译和进入菜单均支持自定义绑定，可按操作组启停。
- **繁体中文**：新增繁体中文翻译目标，可用于网页、PDF 和视频字幕等翻译入口。
- **视频字幕开关**：弹窗中的「视频字幕」与其他功能开关使用一致的样式；关闭后停止字幕翻译并恢复原字幕，重新开启时恢复播放器发现。

## 稳定性与体验

- 修复 X 等单页网站切换帖子后自动翻译间歇失效的问题。站点规则内保留动态监听，需要重新判断语言时等待旧会话停止完成，避免迟到消息干扰新会话。
- 翻译状态区分进行中、已取消和暂时没有正文，避免将中断或加载状态显示为「已翻译 0 段」。
- 段落模式在已打开的页面间同步，段落翻译保留原文的字号、字重与行高。
- 修复切换到外观设置时页面横向跳动，以及保存栏与设置内容重叠的问题。
- 菜单编辑器统一使用项目图标，改善拖动合并、拆分与键盘排序。

## 近期功能一并提供

- 实验性视频字幕翻译：播放器入口、双语字幕、样式设置，以及 SRT / WebVTT 字幕文件导入。
- 实验性豆包翻译接入：Chrome / Edge 可使用同一浏览器中已登录的豆包账号。
- 改善嵌入页面和科学论文网页的正文采集，以及 GitHub 仓库卡片排版。
- 改善论文 PDF 的断词、缩写、科学符号与图文排版；参考文献条目默认保留原文，导出结果支持搜索与复制。
