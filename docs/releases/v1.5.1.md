## WuPage v1.5 正式更新

- 自定义弹窗菜单：左侧预览、右侧添加功能，支持点击移除、拖动吸附、合并与拆分按钮行；GitHub 和官网固定在底部。
- 自定义局部快捷键：调整段落点击、划词原文提交、关闭浮层，以及悬浮球翻译和菜单操作的绑定。
- 新增繁体中文目标语言，以及统一的视频字幕功能开关。
- 修复 X 等单页网站切换帖子后自动翻译失效，以及翻译中断时误报「已翻译 0 段」。
- 修复跨页面的段落模式同步、段落译文字号和外观设置的跳动与遮挡。
- 同时包含实验性视频字幕翻译、实验性豆包接入、嵌入页面采集和论文 PDF 翻译改进。

## v1.5.1 安装包修订

- 修复 Edge 商店拒绝 v1.5.0 安装包的问题：将 PDF 字体来源说明改名为 `font-metadata.json`，保留字体来源、许可证和校验值，避免与根目录扩展清单重名。
- 增加安装包清单数量和字体完整性检查，在上传前拦截重复清单。
